# Sineklik Hollanda

Hollanda'nın en kaliteli sineklik ve perde sistemleri. Plise sineklik, jaluzi, honeycomb ve zip perde çözümleri.

## Özellikler

- ✅ 4-10 gün içinde Hollanda'nın tüm 12 eyaletine teslimat
- ✅ Türkiye üretimi, Avrupa kalitesi
- ✅ Plise sineklik, jaluzi, honeycomb, zip perde seçenekleri
- ✅ Uygun fiyat ve kolay kurulum

## Ürünlerimiz

- Sineklik Sistemleri
- Plise Sineklik
- Plise Perde
- Jaluzi Perde
- Düet Perde
- Honeycomb Perde
- Zip Perde

## İletişim

Bu proje [Fenetre Systems](https://www.fenetresystems.com) tarafından geliştirilmiştir.

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
